# База контактов для холодных кампаний

## contacts_template.csv

Шаблон для загрузки списков в админку Saymen. Перед стартом первой кампании наполните этот файл вашей базой 5000+ контактов.

### Описание колонок

| Колонка | Тип | Обязательная | Описание |
|---|---|---|---|
| `company_name` | string | да | Название юрлица или бренда. Бот не использует, но видно в админке. |
| `phone` | string | да | Телефон в формате `+7XXXXXXXXXX`. Перед загрузкой нормализовать. |
| `industry` | enum | да | Одно из: `pharmacy`, `delivery`, `clinic`, `restaurant`, `retail`, `services`, `other`. Влияет на industry hook в скрипте. |
| `region` | string | нет | Субъект РФ — для часовых поясов и сегментации. |
| `city` | string | нет | Город. |
| `decision_maker_name` | string | нет | ФИО ЛПР, если знаем. Бот обратится по имени. |
| `decision_maker_role` | string | нет | Должность ЛПР. |
| `website` | string | нет | Сайт компании. |
| `known_email` | string | нет | Если уже есть email — используем как fallback, если бот не сможет собрать. |
| `source` | string | нет | Откуда контакт: `2gis`, `rusprofile`, `findbase`, `manual`, `partner`. |
| `notes` | string | нет | Свободные заметки. |
| `status` | enum | служ. | `new` / `dialing` / `called` / `done` / `error`. Заполняется системой. |
| `attempts` | int | служ. | Сколько раз дозванивались. |
| `last_call_at` | datetime | служ. | Последняя попытка. |
| `call_outcome` | enum | служ. | Результат последнего звонка: `email_collected`, `refused`, `callback`, `voicemail`, `no_answer`, `wrong_number`. |
| `collected_email` | string | служ. | Email, который собрал бот. |
| `callback_at` | datetime | служ. | Если попросили перезвонить. |
| `do_not_call` | bool | служ. | Стоп-лист — true означает «никогда не звонить». |

«Служ.» — служебные колонки, заполняются системой во время кампании. При первой загрузке оставлять пустыми (или со значениями по умолчанию: `status=new`, `attempts=0`, `do_not_call=false`).

## Источники базы (если её ещё нет)

- **2GIS API** — точные данные по компаниям с телефонами и категориями. ~50 ₽/тыс. записей через справочник.
- **Rusprofile / Контур.Фокус** — юрлица, ИНН, контакты, аффилиации. Платные.
- **FindBase / Sales Navigator (LinkedIn для РФ)** — отраслевые базы B2B.
- **Парсинг 2GIS / Yandex Maps** — серая зона, формально нарушает ToS, но широко практикуется.
- **Партнёрские базы** — обмен с дружественными CRM-консалтерами.

Перед обзвоном **обязательно прогнать через нормализатор**: проверка формата телефона, удаление дубликатов, отсев номеров мобильных операторов (для B2B нужны городские/8-800), проверка по федеральному стоп-листу (если есть доступ).

## Сегментация для запуска

Не запускайте кампанию сразу на 5000. Стартуйте с **300–500 контактов одной отрасли в одном регионе** — так:
- Скрипт под одну отрасль будет точнее.
- Проще оценить, что не работает.
- Если номер забанят — потеряете не всю базу, а один сегмент.

Рекомендую начать с **аптек в одном регионе** — отрасль однородная, value prop простой, эффект для бизнеса очевидный («фармацевт перестанет отвлекаться на телефон»).
