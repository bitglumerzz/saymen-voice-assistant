# Telegram-бот «Дмитрий» — временный канал для тестирования

Этот канал — **временное решение на тестовый период**, пока браузерный voice-tester и реальная телефония Voximplant не доведены до ума. Цель — дать вам и потенциальным первым клиентам возможность поговорить с ассистентом голосом без сложной инфраструктуры.

Все диалоги пишутся в ту же базу `calls` + `transcript_turns`, что и звонки через Voximplant — увидите их в общем журнале админки Saymen.

## 1. Создать бота в BotFather (5 минут)

1. Открыть в Telegram чат с [@BotFather](https://t.me/BotFather).
2. Отправить команду `/newbot`.
3. Имя бота: `Saymen Demo` (любое читаемое).
4. Username: должен заканчиваться на `_bot`. Например `saymen_demo_bot`. Если занят — пробуйте варианты типа `saymen_voice_bot`, `saymen_test_bot`.
5. BotFather пришлёт сообщение с **токеном** — длинная строка вида `1234567890:AAH...`. **Сохраните**, второй раз не показывает.

(Опционально) Сразу настроить аватар и описание:
- `/setdescription` → выбрать бота → текст: «Голосовой ИИ-ассистент Saymen. Запиши голосовое или напиши текст — отвечу.»
- `/setabouttext` → «Saymen — voice AI для бизнеса.»
- `/setuserpic` → загрузить логотип.

## 2. Прописать токен в проекте

```bash
cd ~/Documents/Claude/Projects/Saymen_bot/orchestrator
```

Открыть/создать `orchestrator/.env` и добавить (если уже есть другие переменные — допишите снизу):

```bash
TELEGRAM_BOT_TOKEN=1234567890:AAH...токен_от_BotFather...
DATABASE_URL=postgres://saymen:saymen_dev_password@localhost:5433/saymen_dev
```

`DATABASE_URL` нужен, чтобы диалоги попадали в БД (если не задан — бот всё равно работает, но без сохранения в журнал).

Для **реального голоса** также нужно:

```bash
ORCHESTRATOR_MODE=dev
OPENAI_API_KEY=sk-...
DEEPGRAM_API_KEY=...
ELEVENLABS_API_KEY=...
ELEVENLABS_VOICE_ID_DMITRY=...
```

Без этих ключей бот будет работать в mock-режиме (текстовые ответы по простой логике, без TTS).

## 3. Поставить зависимость

```bash
cd ~/Documents/Claude/Projects/Saymen_bot/orchestrator
npm install
```

В `package.json` добавлен `node-telegram-bot-api` — `npm install` его подтянет.

## 4. Запустить оркестратор

```bash
npm run dev
```

В логах должно появиться (помимо обычных строк про Fastify):

```
[telegram] 📱 telegram bot started (polling)
```

Если вместо этого `TELEGRAM_BOT_TOKEN не задан — бот не запускается` — значит, .env не подтянулся. Проверьте, что `orchestrator/.env` существует и токен там корректный.

## 5. Поговорить с ботом

Открыть в Telegram чат с вашим ботом (по username, например `@saymen_demo_bot`).

1. Нажать `/start` (или ввести вручную). Получите приветствие от Дмитрия.
2. Записать голосовое сообщение (зажать микрофон в Telegram и говорить). Например: «Здравствуйте, расскажите подробнее».
3. Бот пришлёт два сообщения:
   - 🎙 «Услышал: ...» — что распознала система (полезно для отладки точности ASR).
   - Текстовый ответ Дмитрия + голосовое сообщение с этим же ответом, озвученное ElevenLabs.

Команды:
- `/start` — начать новый диалог (закрывает текущий «звонок» в журнале и заводит новый).
- `/reset` — то же, но без приветствия.

## 6. Видеть диалоги в админке

Все Telegram-диалоги пишутся в БД:
- Один Telegram-чат после `/start` = одна запись в таблице `calls` со значением `direction = 'inbound'`, `caller_number = 'tg:<user_id>'`, `callee_number = 'telegram-bot'`.
- Каждое голосовое или текстовое сообщение = одна строка в `transcript_turns`.

Посмотреть прямо сейчас можно через Drizzle Studio:

```bash
cd ~/Documents/Claude/Projects/Saymen_bot
npm run db:studio
```

Откроется UI на `local.drizzle.studio` — выбрать таблицу `calls` или `transcript_turns`, увидите все ваши Telegram-разговоры.

В следующих итерациях сделаем нормальную страницу журнала звонков в админке Saymen с прослушиванием аудио и поиском по транскриптам.

## 7. Когда отключать Telegram-канал

После того как:
- Браузерный voice-tester заработает (поправим constraint-баг);
- Voximplant + ngrok заработают и пойдут реальные звонки.

Telegram-канал можно оставить как **отдельный продукт** для клиентов, которым неудобно по телефону, или просто отключить, убрав `TELEGRAM_BOT_TOKEN` из `.env`.

## Стоимость теста через Telegram

Примерно как обычный звонок:
- Deepgram ASR (batch): ~0.7 ₽/мин аудио.
- GPT-4o ответ: ~0.5 ₽ за обмен из 5–10 реплик.
- ElevenLabs TTS: ~7 ₽ за минуту озвученной речи.

Один диалог из 6–8 реплик в Telegram обойдётся в ~20–30 ₽. Можете спокойно дать друзьям/коллегам пощупать — даже 100 диалогов = ~2500 ₽.
